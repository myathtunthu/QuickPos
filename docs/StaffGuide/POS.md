# POS / Entry Page Staff Guide

## ရောင်းချမှုအမြန်လုပ်နည်း
1. Product ကိုရှာပါ သို့မဟုတ် barcode scan လုပ်ပါ။
2. Cart ထဲဝင်ပြီး quantity/unit ကိုစစ်ပါ။
3. လိုအပ်ပါက discount ထည့်ပါ။
4. ငွေလက်ခံပြီး checkout လုပ်ပါ။

## Unit ပြောင်းရောင်းနည်း
ဥပမာ ဆန်ကို ပိဿာဖြင့်ရောင်းလိုပါက Cart ထဲတွင် unit dropdown မှ ပိဿာကိုရွေးပါ။ Quantity ကို 0.5, 1, 1.25 စသဖြင့်ထည့်နိုင်သည်။

## မလုပ်သင့်သောအရာများ
- Stock warning ပြနေသည့် item ကို manager ခွင့်ပြုချက်မရှိဘဲ မရောင်းပါနှင့်။
- Unit price ကို မသေချာဘဲ မပြင်ပါနှင့်။
- Barcode မတွေ့လျှင် product အသစ်မထည့်ဘဲ admin သို့မေးပါ။
