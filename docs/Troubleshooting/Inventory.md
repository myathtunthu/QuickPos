# Inventory Troubleshooting

## Product ရှာမတွေ့ပါ

- Product active ဖြစ်/မဖြစ်စစ်ပါ။
- Product name spelling စစ်ပါ။
- Barcode ဖြင့်ရှာပါ။
- Category filter ပိတ်ထား/မထားစစ်ပါ။

## Barcode မဖတ်ပါ

- Barcode number မှန်/မမှန်စစ်ပါ။
- Duplicate barcode ရှိ/မရှိစစ်ပါ။
- Unit barcode သီးသန့်ရှိလျှင် အဲဒီ unit ထဲတွင်ပါထည့်ထားရမည်။
- Scanner/camera permission ခွင့်ပြုထား/မထားစစ်ပါ။

## Stock မမှန်ပါ

- Sale record များစစ်ပါ။
- Purchase record များစစ်ပါ။
- Stock adjustment history စစ်ပါ။
- Unit multiplier မှား/မမှားစစ်ပါ။
- Return/Void record ရှိ/မရှိစစ်ပါ။

## Profit Report မမှန်ပါ

- Cost Price မဖြည့်ထားသော Product ရှိ/မရှိစစ်ပါ။
- Purchase cost ပြောင်းပြီး Product cost မပြောင်းထားလားစစ်ပါ။
- Discount အများကြီးသုံးထားလားစစ်ပါ။

## Low Stock အမြဲပြနေပါသည်

- Minimum Stock value အလွန်မြင့်နေခြင်းဖြစ်နိုင်သည်။
- Stock unit နှင့် minimum unit မကိုက်ညီခြင်းဖြစ်နိုင်သည်။
- Product stock ကို base unit အတိုင်းထည့်ထား/မထားစစ်ပါ။

## Unit Conversion မှားနေပါသည်

- Base Unit ကိုစစ်ပါ။
- Sale Unit multiplier ကိုစစ်ပါ။
- ဥပမာ ၁ ပိဿာ = ၁.၆၃၃ kg ဆိုလျှင် Base Unit kg ဖြစ်ရမည်။
- ၁ ဖာ = ၂၄ ဘူး ဆိုလျှင် Base Unit ဘူး ဖြစ်ရမည်။
