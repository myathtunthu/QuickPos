# Inventory User Guide

## Inventory ဆိုတာဘာလဲ
ကုန်ပစ္စည်း၊ ကုန်ကြမ်း၊ လက်ကျန်စတော့များကို စီမံခန့်ခွဲရန် အသုံးပြုသည်။

## Product အသစ်ထည့်နည်း
1. Inventory > Add Product
2. Product Name ဖြည့်ပါ
3. Base Unit ရွေးပါ
4. Cost Price / Sale Price ဖြည့်ပါ
5. Save

## Myanmar UOM
- 1 ပိဿာ = 100 ကျပ်သား
- 1 တင်း = 16 ပြည်
- 1 kg = 1000 g

## Multi Unit ဥပမာ
ဆန်
- Base Unit = kg
- ပြည် = 2.56 L equivalent business rule
- တင်း = 16 ပြည်

## Stock Adjustment
Inventory > Adjust Stock မှ ဝင်/ထွက် စာရင်းပြင်နိုင်သည်။
