# Inventory User Guide

Use the Inventory page to create products, manage stock, configure barcodes, and set up units of measurement for Myanmar retail workflows.

## 1. Product creation

1. Open **Inventory**.
2. Tap **Add Product**.
3. Enter product name, category, barcode, cost price, sale price, and opening stock.
4. Choose the correct base unit.
5. Save the product.

## 2. Units of measurement

The system supports both international and Myanmar local units.

- Count units: pcs, dozen, pack, carton, set
- Weight units: g, kg, ton, viss, tical, peh
- Rice/grain units: tin, pyi, cup/can
- Volume units: ml, liter, US gallon, UK gallon
- Length units: mm, cm, m, inch, ft, yard, roll

## 3. Myanmar UOM examples

- 1 viss = 100 tical
- 1 tical = 16 peh
- 1 kg = 1000 g
- 1 tin = 16 pyi
- 1 liter = 1000 ml

## 4. Multi-unit setup

Set one base unit for stock keeping. Add sale units with a multiplier so staff can sell in different units.

Example for rice:

- Base unit: kg
- Sale unit: pyi
- Sale unit: tin
- Sale unit: bag

## 5. Stock alert

Set the minimum stock level. When stock reaches that amount, the product will appear as low stock.

## 6. Barcode usage

Use one barcode per product or per package unit. Avoid duplicate barcodes.

## 7. Best practices

- Keep cost price accurate because profit reports depend on it.
- Do not delete products with transaction history. Mark them inactive instead.
- Check stock after purchases, returns, and adjustments.
