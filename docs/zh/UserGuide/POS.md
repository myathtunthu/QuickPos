# POS 使用指南

POS 页面用于销售商品、扫描条码、管理购物车、收款和打印小票。

## 1. 开始销售

1. 搜索或扫描商品。
2. 商品有多单位时选择正确单位。
3. 输入数量。
4. 检查购物车。
5. 点击结账。

## 2. 缅甸单位销售

商品可按 viss、tical、pyi、tin、carton、pack、pcs 等单位销售，具体取决于商品设置。

## 3. 购物车检查

系统会在保存销售前检查数量、库存、折扣和收款金额。

## 4. 赊账销售

赊账销售必须选择客户，并会增加客户欠款。

## 5. 最佳实践

- 结账前确认单位和数量。
- 没有客户资料不要做赊账销售。
- 保存交易前确认现金金额。
