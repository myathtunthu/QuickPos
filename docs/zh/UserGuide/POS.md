# POS 销售录入 使用指南

用于扫码销售、选择单位、设置折扣、收款、挂单和结账。

## 基本流程

1. 从侧边栏或底部导航打开页面。
2. 查看搜索、筛选、表格和操作按钮。
3. 保存前确认金额、日期、客户/供应商、单位和付款方式。
4. 重要操作完成后，可到 Records 或 Reports 中核对。

## 注意事项

- 每位员工应使用自己的账号。
- 不要共享管理员密码。
- 成本价、单位换算和付款数据会影响报表，必须准确。
- 如果数字不正确，先到 Records 中查找原始单据。

## 常见问题

- 数据不显示：检查网络和账号权限。
- 按钮不可用：请管理员检查角色权限。
- 库存或欠款不正确：检查销售、采购、付款或库存调整记录。

## 最佳实践

- 每天关店前核对当天交易。
- 保留客户电话和供应商单号。
- 不要随意删除历史记录。
